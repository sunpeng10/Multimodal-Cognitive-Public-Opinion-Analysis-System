# 图像情感识别实验记录

本目录用于保存 image based affective recognition 方向可复核的实验过程与结果。目前已归档 CAER-Net-S 的单图推理与前端工程验证，尚无本方向的数据集性能评估记录。

开始实验时，复制 [实验模板](experiment_template.md)，使用实际实验标识命名文档；完成数据、划分、环境与运行记录后，再将真实记录登记到下表。计划、预期和观察结果应分别说明。未运行的项目不得填写为已完成，不得以示例数字代替结果。

| 实验记录 | 状态 | 说明 |
| --- | --- | --- |
| [CAERS-FRONTEND-001：CAER-Net-S 单图推理与可视化前端](CAER-Net-S-Frontend.md) | 历史工程验证已有证据；2026-10-31 整合归档 | 第三方静态图像实现；CPU 推理、真实 attention/fusion、Gradio 前端及导出验证。已核对本地 JSON 与截图，报告记录来源，附件未上传；没有数据集准确率/F1 或训练结果。 |

当前不将其他研究方向的实验登记为本方向结果。若后续复用已有方法，应在新实验中写明原始来源、改动和实际验证范围。

记录建议：保存代码版本、配置、随机种子、日志与产物位置；保持训练集、验证集和测试集的使用边界；对多次运行结果说明汇总方法；结论应能追溯到对应结果与失败样本。
