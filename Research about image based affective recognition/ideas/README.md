# 研究问题与 idea

本目录保存图像情感识别方向待验证的研究问题、候选方法与验证设计。目前内容为研究计划，不代表已完成实验、已确认性能提升或已证实的创新点。

- [研究问题与候选验证方案](research_questions.md)：人物与上下文、冲突判断、跨数据集泛化、不可靠结果识别，以及与文本情感结果的关联。
- [idea 模板](idea_template.md)：以 A + B = C 明确已有基线、问题、候选模块与验证方案。
- [实验记录目录](../experiments/README.md)：记录实际执行、结果与可复核证据。

使用时先定义问题与可证伪假设，再填写来源和对照方案。开始运行后，将实验过程写入实验目录，并在 idea 中关联真实记录。结论必须与证据对应；未验证的预期保留“计划”或“待验证”状态。
